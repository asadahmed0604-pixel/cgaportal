Data Backup & Transfer (Laptop → Laptop)

Data isi browser mein save hota hai. Mahiney mein aik dafa backup file zaroor download karein.

Dosre laptop par data le jane ka tareeqa:
1. Is laptop par "⬇ Download Backup" dabayein — ek JSON file download hogi.
2. Wo JSON file (aur ye HTML file) USB/email se dosre laptop par le jayein.
3. Dosre laptop par ye HTML file kholein aur "⬆ Import Backup" daba kar wo JSON file select karein.
4. Sara data — students, photos, fees, attendance, exams, homework — waisa ka waisa aa jayega.

File select nahi ho rahi (khaas kar mobile par)? Backup file ko Notepad ya kisi text editor mein kholein, sab kuch copy karein, aur "Text paste kar ke import" dabayein.
