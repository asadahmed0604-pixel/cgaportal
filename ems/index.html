Data Backup & Transfer (Laptop → Laptop)

Data is saved in this browser. Download a backup file at least once a month.

How to move data to another laptop:
1. On this laptop press "⬇ Download Backup" — a JSON file will download.
2. Take that JSON file (and this HTML file) to the other laptop via USB/email.
3. On the other laptop open this HTML file, press "⬆ Import Backup" and select that JSON file.
4. All data — students, photos, fees, attendance, exams, homework — will come across as is.

Can't select a file (especially on mobile)? Open the backup file in Notepad or any text editor, copy everything, and press "Import by pasting text".

🗑 Delete all student data

A clean start for a new session: all students and their records — fee challans, attendance, exam marks, homework "done" marks and items issued to students (issuance) — are deleted. Employees, income/expense, inventory, inquiries, subjects and settings stay as they are. A backup file is downloaded automatically before deleting.
